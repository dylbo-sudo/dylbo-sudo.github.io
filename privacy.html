Privacy policy

Omamail is a desktop mail client used only by its owner on their own computer.

What data is accessed

With the user's consent, Omamail accesses the signed-in user's Gmail messages and Google Calendar events through Google's APIs, so it can display, send and organise mail and show reminders.

Where data goes

  • Data is processed only on the user's own computer. There is no server operated for Omamail.
  • Sign-in tokens are stored in the system keyring on that computer.
  • No data is sold, shared with third parties, or used for advertising.

Omamail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
